The Zwane website is intentionally a static, portable presentation site inside the hosted web artifact shell. The user requested vanilla HTML, CSS, and JavaScript rather than a component framework, and the current implementation preserves that constraint while using the artifact shell for preview and publishing.

Generic architectural visuals are concept studies only, not company portfolio claims. Keep those labels and avoid adding invented clients, locations, project names, awards, qualifications, registrations, or completed-work claims.

**Why:** The practice brief prioritizes credibility and explicitly prohibits unsupported professional or project claims.

**How to apply:** Preserve the current factual copy and labeling when adding pages, assets, or integrations. Only connect enquiry submission to a real destination once the user confirms the destination.
