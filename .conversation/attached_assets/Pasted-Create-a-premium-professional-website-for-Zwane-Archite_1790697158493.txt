CORE WEBSITE GOAL

Build a website that immediately makes Zwane Architectural and Engineering Solutions look like an established, credible professional practice.

The website should communicate:

* Architectural design expertise
* Technical precision
* Professional project planning
* Engineering capability
* Attention to detail
* Practical, buildable solutions
* A clear path for potential clients to request a consultation

Do NOT make the website look like a generic construction company website. This is an architectural and engineering practice, so the visual identity should feel more sophisticated, technical, precise and design-led.

DESIGN DIRECTION

Create a premium architectural studio aesthetic inspired by modern South African architecture and high-end architectural portfolios.

Visual characteristics:

* Clean layouts
* Strong architectural photography
* Large typography
* Generous whitespace
* Geometric grid structures
* Subtle technical/drafting-inspired details
* Elegant transitions
* Strong visual hierarchy
* Sophisticated neutral colour palette
* Dark charcoal / warm white / concrete grey with a restrained architectural accent colour
* Avoid excessive bright colours
* Avoid generic corporate stock imagery
* Avoid the typical blue-gradient engineering website look
* Avoid a cyber/tech aesthetic

The site should feel like a combination of:

* Architecture studio
* Engineering consultancy
* Professional project portfolio
